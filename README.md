# AliExpress Network Research Platform

## Project Overview

This project aims to detect suspicious review manipulation and coordinated seller behavior on AliExpress using large-scale product-reviewer graph analytics.

The system is designed as a cloud-native Azure data engineering platform capable of collecting marketplace data, storing it in Azure Blob Storage and Azure PostgreSQL, constructing product-reviewer graphs, and performing anomaly detection using graph analytics and machine learning.

## Research Objective

Can network-based analytics identify coordinated review manipulation and suspicious seller behavior on AliExpress using publicly available marketplace data?

## Technology Stack

* Azure Blob Storage
* Azure Database for PostgreSQL
* Azure Container Apps
* Python
* Playwright
* PostgreSQL
* NetworkX
* Apache Spark (later phase)
