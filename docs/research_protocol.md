# Research Protocol

## Project Title

Network-Based Detection of Suspicious Review Manipulation on AliExpress Using Large-Scale Product-Reviewer Graph Analytics

## Research Question

Can network-based analytics identify coordinated review manipulation and suspicious seller behavior on AliExpress using publicly available marketplace data?

## Hypotheses

H1: Products involved in review manipulation exhibit higher reviewer overlap than normal products.

H2: Suspicious products form dense communities in the product-reviewer graph.

H3: Network features outperform simple metadata features such as average rating or review count.

H4: Unsupervised graph clustering can identify suspicious seller groups without labeled fraud data.

## Target Dataset

* Products: 50,000
* Sellers: 8,000
* Reviews: 1,500,000
* Unique reviewers: 400,000
* Collection duration: 30–60 days

## Deliverables

* Large-scale reproducible dataset
* Product-reviewer graph
* Graph analytics pipeline
* Anomaly detection model
* Research paper
